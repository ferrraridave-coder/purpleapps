LLM Pro

Premium AI chat and image generation for iPhone & iPad

View on the App Store

One App. Two Superpowers.

LLM Pro combines high-performance AI chat with built-in AI image generation. Switch between Chat and Images instantly, with clear limits and a fast, polished Pro workflow.

Premium AI Chat

LLM Pro includes a free cloud chat option and a premium subscription that unlocks curated high-performance cloud AI models. Some models support real-time web search and vision for image analysis.

No account is required — start chatting instantly.

Key Features

  • Curated high-performance cloud AI models (Pro subscription)
  • Free cloud chat available (no account required)
  • Real-time web search on supported models
  • Vision support for image analysis on supported models
  • AI image generation and image-to-image editing
  • Up to 100 images per month included with Pro
  • Advanced image parameters and multiple image models
  • Transparent reasoning display (supported reasoning models)
  • Document uploads (PDF, Word, and text) on supported models
  • Advanced generation controls: temperature and sampling settings
  • Custom system prompts and output filtering options
  • Conversation history with model identification
  • iPhone and iPad optimised interface

AI Image Generation

Create and edit images directly inside LLM Pro. The Images tab supports text-to-image generation and image-to-image editing with advanced controls. Your monthly image allowance is clearly displayed in-app.

Image generation is powered by third-party AI services (including Replicate). Feature availability depends on the selected model.

Bring Your Own API Key (Advanced)

For advanced users, LLM Pro supports optional bring-your-own API keys for OpenRouter, OpenAI, and xAI. Your API keys are stored only on your device.

When using third-party providers via BYOK, content is sent directly to those providers, and you are responsible for any associated costs.

Subscription and billing are managed through the App Store. Limits and supported features are shown in-app.
