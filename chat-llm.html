Private by Design

Chat LLM is built for privacy-conscious users. Use optional on-device AI for offline chat, or connect your own API keys for powerful cloud models — without creating an account.

AI That Can Work Offline

Chat LLM supports an optional on-device AI model for offline chat. When using local AI, conversations stay on your device and do not require an internet connection.

Prefer cloud models? Use free cloud chat, or connect your own OpenRouter, OpenAI, or xAI API keys for access to a wide range of external models, including vision-capable and reasoning models where supported.

Key Features

  • Optional local AI for offline chat (no internet required)
  • Free cloud chat available (no account required)
  • Bring your own API key (BYOK) for OpenRouter, OpenAI, and xAI
  • Access to a wide range of third-party models (provider-dependent)
  • Vision support: upload images for analysis on supported models
  • Document uploads (PDF, Word, and text) on supported models
  • Real-time voice chat (optional, requires compatible API key)
  • Advanced generation controls
  • Custom system prompts and output filtering
  • Conversation history with model identification
  • CloudKit sync across devices (where enabled)
  • Long-press messages to copy and share
  • Dark mode interface optimised for readability

Built for Privacy-Conscious Users

Chat LLM does not require user accounts. Optional API keys are stored securely on your device using iOS Keychain.

When using third-party providers via your own API keys, content is sent directly to those providers to generate responses. Provider capabilities and retention policies may vary.

Your data remains under your control.
