Flexible by design

Use local AI for private offline chats, try free cloud chat without an account, or connect your own provider keys when you want more control over models and capabilities.

Voice chat with Gemini.

Chat LLM now uses Google Gemini for real-time voice chat. Gemini also supports richer multimodal workflows, including image and photo uploads on supported models, so conversations can include more than plain text.

Provider features can vary by model and account, but the app is built to make those options easier to reach from one focused iOS interface.

Key features

  • Optional local AI for offline chat with no internet connection required
  • Free cloud chat available without creating an account
  • Bring your own API key for supported providers including OpenRouter, OpenAI, Google Gemini, and xAI text models
  • Google Gemini real-time voice chat
  • Image and photo uploads on supported vision-capable models
  • Document uploads for PDF, Word, and text files where supported
  • Advanced generation controls, custom system prompts, and output filtering
  • Conversation history with model identification
  • CloudKit sync across devices where enabled

Built for privacy-conscious users.

Chat LLM does not require a user account. Optional API keys are stored securely on your device using iOS Keychain.

When you use third-party providers, your prompts, uploads, or voice input are sent to the selected provider to generate a response. Their own privacy and retention policies apply.
