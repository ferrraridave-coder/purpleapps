1. Description of the App

Copy Tiles: Keyboard is a custom keyboard utility for iPhone and iPad. It allows you to create, organise, and instantly insert reusable text tiles from a custom keyboard in any app. Key features include:

  • Unlimited tiles and categories with drag-and-drop reordering
  • Adjustable tile sizes (Small, Medium, Large)
  • Clipboard history accessible from the keyboard
  • Full iCloud sync across devices via Apple CloudKit
  • Real-time layout updates between the app and keyboard extension
