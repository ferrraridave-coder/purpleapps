Frequently Asked Questions

What is Chat LLM?

Chat LLM is a privacy-focused AI chat app for iPhone and iPad. It supports optional on-device (local) AI for offline chat, free cloud chat, and bring-your-own API keys (BYOK) for accessing additional models from third-party providers.

Do I need an account or API key?

No account is required to use Chat LLM. You can start with free cloud chat without an API key. If you choose to use third-party providers (such as OpenRouter, OpenAI, or xAI), you will need an account and API key from that provider. API keys are stored only on your device.

What models are supported?

Chat LLM includes a free cloud model for basic chat, and may support an optional local model for offline use. With BYOK enabled, you can access a wide range of third-party models (text, vision, and reasoning, where supported by the provider). Available models and features depend on the provider you connect and the specific model selected.

Can I upload images or documents?

Yes, image and document uploads are available on supported models. Feature availability depends on the model and provider. Free cloud chat is typically text-only.

What is Voice Chat?

Chat LLM supports real-time voice conversations when you connect a compatible provider (such as xAI) using your own API key. You are responsible for any costs charged by the provider.

How is my data handled?

Chat LLM does not require user accounts and does not store your prompts, uploads, or API keys on our servers. When using third-party providers via BYOK, your content is transmitted to that provider to generate responses. Provider data handling and retention policies vary — please refer to the provider’s privacy policy for details.

How do I report a bug?

Please email a description of the problem and, if possible, include screenshots or steps to reproduce it.
