Frequently Asked Questions

What is LLM Pro?

LLM Pro is a premium AI app for iPhone and iPad that combines high-performance AI chat with built-in AI image generation. It includes curated cloud models, optional web search, and a subscription with clear usage limits.

Do I need an account?

No. LLM Pro does not require user accounts. You can start chatting immediately. Subscriptions are managed through the App Store.

How does image generation work?

LLM Pro includes AI image generation and image-to-image editing. A monthly image allowance applies (currently up to 100 images per month), and your remaining usage is shown in-app.

Can I use my own API keys?

Yes. LLM Pro supports optional bring-your-own API keys (BYOK) for providers such as OpenRouter, OpenAI, and xAI. API keys are stored only on your device.

How is my data handled?

LLM Pro does not store your prompts, images, or API keys on its own servers. Content is transmitted to third-party providers only to generate responses. Please see the Privacy Policy for details.
